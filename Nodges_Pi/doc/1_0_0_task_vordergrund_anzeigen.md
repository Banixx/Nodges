# Anzeigen von Tasks im Vordergrund in Antigravity

In Antigravity koennen laufende Hintergrund-Tasks und Terminal-Prozesse auf verschiedene Weise im Vordergrund betrachtet und verfolgt werden.

## Moeglichkeiten zur Anzeige

1. **Auxiliary Pane / Seitenleiste (Background Tasks & Terminals)**:
   - In Antigravity 2.0 sowie in der Antigravity IDE befindet sich im Hilfspanel (Auxiliary Pane) der Reiter **Background Tasks** bzw. **Terminals**.
   - Ein Klick auf die jeweilige Task oeffnet die Live-Konsole und zeigt den Ausgabestrom im Vordergrund an.

2. **Terminal-Tab im Editor**:
   - Jede aktive Task ist an eine eigene Terminal-Sitzung gebunden, die ueber die Terminal-Uebersicht fokussiert werden kann.

3. **Interaktion und Log-Einsicht**:
   - Ueber das Task-Management koennen Status und Logs abgefragt sowie Eingaben an laufende Prozesse gesendet werden.
