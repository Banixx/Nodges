# Wiederholung der Installation von @earendil-works/pi-coding-agent

## Status
Die globale Installation des Paketes `@earendil-works/pi-coding-agent` im Docker-Container `pi-harness` wurde erneut gestartet.

- **Befehl**: `docker exec pi-harness npm install -g @earendil-works/pi-coding-agent`
- **Ziel**: Das CLI-Tool `pi` global im Container verfuegbar zu machen.
