# Ein Gedanke fuer Nodges: Ueberblendung von Systemen

Ein Gedanke fuer Nodges, eine Idee: Beim Ueberblenden mehrerer von verschiedenen Menschen erstellten Systemen kann man auf Schwarz-Weiss umschalten. Alternativ kann eine der Darstellungsebenen, die bislang die Farbe innehatte, die Farbvisualisierung exklusiv fuer die Ueberblendung nutzen, waehrend der Rest in blasse Farben oder Schwarz-Weiss (Grautoene) zuruecktritt.
