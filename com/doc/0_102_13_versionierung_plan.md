# Versionierungsplan (SGC Workflow)

## Ziel
Erhoehung der Patch-Version des Projekts Nodges von `0.102.13` auf `0.102.14`.

## Schritte
1. Aktualisierung der `package.json` (`"version": "0.102.14"`).
2. Ausfuehrung von `git add .`.
3. Ausfuehrung von `git commit -m "0.102.14"`.
4. Ausfuehrung von `git push`.
