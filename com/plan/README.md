# plan/ — laufende Vorhaben

Ein File je Vorhaben. Dateiname mit Versionspraefix aus `package.json` (aus `0.106.3` wird `0_106_3_`).

**Zweck:** Alles, was mehrere Schritte braucht und ueber eine einzelne Antwort hinausgeht.
Nicht fuer abgeschlossene Arbeit — das gehoert als Praefix-Bericht nach `../doc/`.

**Vorlage fuer eine neue Datei:**

```
# <Kurztitel>

Stand: YYYY-MM-DD · Harness: piCon/conT · Version: 0.106.x

## Ziel
Ein bis zwei Saetze.

## Schritte
- [ ] Schritt 1
- [ ] Schritt 2

## Offene Fragen
- ...
```

Wenn ein Vorhaben erledigt ist: Datei nach `../doc/` verschieben oder hier loeschen und das Ergebnis in
`../doc/<version>_<titel>.md` dokumentieren. `../todo.md` entsprechend aufraeumen.
