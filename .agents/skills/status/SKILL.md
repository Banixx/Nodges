# status (conT)

Verbindliche Quelle: `tools/nodges-git.sh` im Repo.

Ausfuehren:

```bash
bash tools/nodges-git.sh status
```

Zeigt Branch, Version, letztes Tag, letzten Commit, wie viele Commits lokal vorliegen und die Zahl offener Dateien. Kein Pull, kein Reset.
