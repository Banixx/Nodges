# Start Website Workflow

Dieser Workflow startet den Entwicklungsserver und öffnet die Webseite im Browser.

## Schritte

1. **Server starten**
   // turbo
   Führe `npm run dev` im Projektverzeichnis aus.
   - Command: `npm run dev`
   - Background: True
   - Wait: 3000ms

2. **Browser öffnen**
   Öffne den Browser unter `http://localhost:5173/`.
   - URL: `http://localhost:5173/`

3. **Status prüfen**
   Überprüfe, ob die Seite korrekt geladen wurde und zeige einen Screenshot.
