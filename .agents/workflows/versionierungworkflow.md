---
description: Erhöht die Version von Nodges um eine minor oder major stelle
---

Mit dem Command "Versionierung" als Prompt, löst der User die Erhöhung des des hintersten Zählers aus. Bsp. 0.94.01 -> "Versionierung" -> 0.94.02.

Mit dem Command "Versionierung minor" als Prompt, löst der User die Erhöhung des Minor Zählers aus. Bsp. 0.94.01 -> "Versionierung minor" -> 0.95.00.

Ohne angabe von "minor" wird automatisch der hinterste Zähler erhöht.

Die Versionsangabe wird in package.json angepasst.
