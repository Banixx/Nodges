# Uebersicht der globalen Workflows

Hier ist eine Liste aller aktuell in Antigravity 1.23.2 verfuegbaren Workflows, die ueber das Prompt-Eingabefeld gestartet werden koennen:

- **/archiv_sessions**: Archiviert alte Antigravity Sessions, um das 25-Session Limit in der UI zu umgehen.
- **/devcontainer-setup**: Automatisiertes Erstellen der DevContainer-Umgebung fuer ein Projekt.
- **/fragen**: Sendet vordefinierte Fragen direkt an das LLM.
- **/idee**: Sammelt Ideen zur zukuenftigen Entwicklung von Nodges.
- **/such**: Durchsucht alte Brain-Logs und Archive nach Kontext zum aktuellen Thema.
- **/versionierungworkflow**: Erhoeht die Version von Nodges um eine Minor- oder Major-Stelle (passt `package.json` und `index.html` an).
- **/web**: Startet die `index.html` auf einem lokalen Webserver.

*(Alle diese Workflows liegen als Markdown-Dateien im Verzeichnis `C:/Users/ich/.gemini/antigravity/global_workflows/`)*
